YOUR OWN PHOTOS GO HERE
-----------------------
Drop a .jpg / .jpeg / .png / .webp file in this folder and the site picks it up
automatically. No code changes needed. Restart `npm start` after adding files.

File names (slug = lowercase place id):
  munnar.jpg        main photo for Munnar        (more: munnar-1.jpg, munnar-2.jpg ... fill the gallery)
  tada.jpg          main photo for Tada          (more: tada-1.jpg, tada-2.jpg ...)
  kabaddi.jpg       Kabaddi action photo (used on Home and the Kabaddi page)
  kabaddi-1.jpg ... extra Kabaddi gallery photos

Dream destinations can be replaced too, using their ids:
  kyoto, bali, swiss-alps, istanbul, patagonia, cappadocia, meghalaya,
  ladakh, rajasthan, varanasi, fuji, maldives, himalaya

Tip: keep each photo under ~400 KB (about 1800px wide) so pages load fast.

GETTING A REAL TADA FALLS PHOTO
-------------------------------
Free-to-use photos of Tada (Ubbalamadugu) Falls are on Wikimedia Commons:
  https://commons.wikimedia.org/w/index.php?search=Tada+Falls+Ubbalamadugu&ns6=1
Download one (or use your own!), rename it  tada.jpg  and put it in this folder.
If it is a Commons photo, add the photographer's name + licence to the `credit` field of the
Tada entry in src/data/visitedPlaces.js, e.g.  credit: 'Photo: Name / Wikimedia Commons (CC BY-SA 4.0)'
